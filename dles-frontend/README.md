# DLES Frontend

Vue 3 + TypeScript + Vite web client. The app lives in [`DLES/`](DLES). See the [root README](../README.md) for the overall setup.

```bash
cd DLES
npm install
npm run dev     # http://localhost:5173
npm run build
```

The backend address is configured in `DLES/src/util/request.ts`.
